# 🏆 Junior Clash — Kids Quiz Battle (Class 1 vs Class 3)

A vibrant, mobile-first educational quiz competition web app built for siblings with an age gap:
- 🌟 **Younger Child:** Age 6 • **Class 1 (Grade 1)**
- 🚀 **Elder Child:** Age 8 • **Class 3 (Grade 3)**

---

## 📱 How to Run and Play on Mobile

### Step 1: Start the App on your Computer
Double click `start.bat` or run in terminal:
```bash
npm run dev
```

### Step 2: Open on Mobile
Vite will output two URLs:
- **Local:** `http://localhost:3000`
- **Network:** `http://192.168.x.x:3000` *(e.g. `http://192.168.1.5:3000`)*

Make sure your mobile phone is connected to the same home Wi-Fi network as your computer, then open the **Network URL** in mobile Chrome or Safari!

### Step 3: Install as an App (Optional)
Tap the browser menu (`⋮` in Chrome or Share button in Safari) and tap **"Add to Home Screen"**. It will run fullscreen like a native mobile app!

## 🎯 Key Features

### 1. Fair Handicap Balancing
When competing:
- Your **Class 1 child** gets questions carefully calibrated for Class 1 (phonics, single/double digit addition & subtraction under 20, Hindi varnamala, direction arrows, living things).
- Your **Class 3 child** gets questions calibrated for Class 3 (times tables, division, perimeter, grammar & parts of speech, Hindi vyakaran & muhavare, coding loops, photosynthesis, solar system).
- Both earn equal stars and combo streaks for correct answers!

### 2. Built-in Voice Read-Aloud (Text-to-Speech)
- Tap the **speaker icon 🔊** on any question to hear it read aloud in a gentle, warm voice.
- Automatically handles **Hindi** (Devanagari) and **English**.
- Essential for 6-year-olds who are still learning to read independently!

### 3. Sound Effects & Confetti Celebration
- Ascending pleasant chimes for correct answers
- Playful gentle boing for retries
- Combo streak bonuses 🔥
- Grand victory fanfare and colorful confetti blast at match end!

### 4. Game Modes
1. **Pass & Play (Turn-by-Turn):** The children take turns on one phone. Big banners announce whose turn it is.
2. **Split Screen Duel:** Two children tap simultaneously on top/bottom halves of the phone or tablet.
3. **Solo Practice:** Either child can practice alone at their own pace without timer stress.

### 5. Educational Explanations & Mistake Review
- Every question includes a *"Did You Know? 💡"* learning tip.
- At the end of every match, parents and kids can expand the **"Review & Learn from Mistakes"** drawer to see what went wrong and how to solve it next time.

## 📚 Syllabus Covered

| Subject | Class 1 (Age 6) | Class 3 (Age 8) |
| :--- | :--- | :--- |
| **Math (गणित)** | Counting, Add & Sub under 20, 2D shapes, skip counting (2s, 5s, 10s) | Multiplication tables (2-12), division, fractions, perimeter, word problems |
| **English** | Phonics, sight words, rhyming words, opposites, plurals | Parts of speech (nouns, verbs, adjectives), spellings, proper nouns, prepositions |
| **Hindi (हिंदी)** | वर्णमाला (स्वर, व्यंजन), पशु-पक्षी, फलों के नाम, सरल विलोम | संज्ञा पहचान, विलोम शब्द, पर्यायवाची, सरल मुहावरे, शुद्ध वर्तनी |
| **Coding & CS** | Direction arrows (⬆️ ⬇️ ⬅️ ➡️), robot steps, computer parts (monitor, mouse, keyboard) | Algorithms, loops & repetition, debugging bugs, CPU, input vs output devices |
| **Natural Science** | Living vs non-living, 5 senses, plant parts, day/night, weather | Photosynthesis/chlorophyll, food chains, human organs (heart, lungs), solar system |
